Privacy Policy

Last updated: April 2026
sebs.health is a personal health dashboard built for private use by a single individual. This app is not a commercial product and does not collect, sell, or share data with any third parties.

Who this app is for

sebs.health is a personal health tracking application used exclusively by its owner. It is not a public-facing product and is not available for general registration.

What data is collected

The following personal health data is stored when logged by the app user:

  • Sleep metrics (duration, efficiency, restorative sleep)
  • Recovery data (HRV, resting heart rate, recovery score) via WHOOP integration
  • Daily step count and body weight via Apple Health integration
  • Calorie and nutrition data entered manually or via AI photo estimation
  • Habit and supplement tracking entries
  • Progress photos uploaded voluntarily

How data is stored

All data is stored in a private Supabase database protected by row-level security. Only the authenticated account owner can read or write their own data. Progress photos are stored in private encrypted storage and are never publicly accessible.

Third-party integrations

This app connects to the following third-party services solely to retrieve health data on behalf of the account owner:

  • WHOOP — sleep and recovery metrics are fetched via the WHOOP Developer API using OAuth 2.0. No WHOOP data is shared with any other party.
  • Apple Health — weight and step data is sent from the device via a personal iPhone Shortcut. No data is transmitted to any party other than the user's own database.
  • Anthropic Claude API — food photos are sent to the Claude API for calorie estimation. Images are processed transiently and are not stored by Anthropic beyond normal API logging policies.

Data sharing

No personal data is shared with, sold to, or accessible by any third party. This application has no advertising, analytics tracking, or external data sharing of any kind.

Data retention

Data is retained in the user's private database indefinitely unless manually deleted by the account owner. The account owner can delete their account and all associated data at any time by contacting the app administrator.

Cookies

This application uses a single authentication session cookie to keep the user logged in. No tracking or advertising cookies are used.

Your rights

As the sole user of this application, the account owner has full control over all data stored. Data can be exported or deleted upon request.

Contact

For any questions about this privacy policy or data handling, contact the app owner directly.
